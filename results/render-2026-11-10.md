# F4 — rendered concealment, 553 job postings (2026-11-10)

**Status: run once, not pre-registered.** Unlike F1 this frame had no frozen
protocol before collection; it was built to answer `NEXT-STUDY.md` G4 and the
deviation is recorded in [`../deviations.md`](../deviations.md). Read the
limitations before quoting any number here.

Population: job postings — content an agent ingests for matching and screening.
Sampled systematically (40 per board, id-sorted) from three ATS families:
Greenhouse 320 · Ashby 153 · Lever 80
= **553 pages, 14 employers**, fetched once on 2026-11-10. Provenance and per-page
SHA-256 in `render-2026-11-10.manifest.jsonl` (job titles dropped: they are page text).

Instrument: headless Chromium 156, 1280×900, JavaScript **enabled** (see
deviation 2), computed style per element, 13 concealment predicates; plus the
Unicode channel and the markup surfaces (attributes, JSON-LD, meta description,
`<template>`). Concealed strings are never stored or published as text: only
SHA-256 prefix, length, mechanism and a stage-2 verdict.

## Result

| Channel | Docs | Prevalence (95% CI) | Instruction-shaped |
| --- | ---: | --- | ---: |
| Text not visible to a reader (computed style) | 325/553 | **58.8%** (54.6–62.8%) | **0** |
| — restricted to the job-description body | 49/553 | 8.9% (6.8–11.5%) | 0 |
| Invisible Unicode code points | 40/553 | 7.2% (5.4–9.7%) | 0 |
| Attributes ≥40 alphanumerics (alt/title/aria/data-*) | 194/553 | 35.1% (31.2–39.1%) | 0 |
| JSON-LD blocks | 316/553 | 57.1% (53.0–61.2%) | 3 |
| Meta description | 278/553 | 50.3% (46.1–54.4%) | 2 |
| `<template>` content | 0/553 | 0.0% | 0 |

Render channel detail: **5,728 concealed elements** (10.4 per page), but only
**149 distinct strings** — median 25 characters, longest 49,
65 of them under 20 characters.
They are UI state (`display:none` panels, dialog labels, a11y text), not prose: the
6 distinct strings that appear inside the job body are
17 characters at most.

The Unicode channel is one code point: **U+2060 WORD JOINER**, 40 pages, all on
Greenhouse — the same benign paste-artifact class as F1's variation selectors.
`<template>` is unused by all three ATS.

### The five instruction-shaped hits, adjudicated

The stage-2 classifier fired on 5 machine-only surfaces
(3 JSON-LD, 2 meta description) on 4 of 553 pages. All five sit inside
schema.org `JobPosting` objects (or a meta description copied from one) and are
third-person prose about models or recommendations — none carries a second-person
directive, a role-play frame, a wrapper tag, an assistant turn or an "ignore"
clause. Adjudicated: **0 concealed or hidden instructions** in 553 pages; the
5 hits are false positives of the shape classifier on job prose,
a 0.7% page rate (5 hits) worth knowing before anyone ships a
text-channel detector.

## Detection performance and what the null is worth

Two independently authored payload sets (16 instruction + 12 data-injection + 8
other payloads each; 36 payloads from a separate model instance, no sight of the
detector), each placed in one modelled and one unmodelled mechanism on a real job
description: **144 cases**.

| Mechanism | Fired | Payload text recovered |
| --- | --- | --- |
| 8 modelled CSS mechanisms | 68/72 = **94.4%** (86.6–97.8%) | 68/72 |
| 4 unmodelled (1.5px text, `::before`, opaque overlay, collapsed `<details>`) | **0/72** | 0/72 |
| Instruction payloads, end to end | **12/64 = 18.8%** (11.1–30.0%) | — |
| Data-injection payloads, end to end | **0/48** | — |

So the honest bound on a concealed instruction in this population is
**≤2.9%** (95%), not the 0.54% a perfect instruction stage would give:
P(0 hits | 1% prevalence) = 35% at the measured sensitivity, and each of the
12 detections required both the mechanism and the phrasing to match.

| Prevalence | Design | sens | FPR | PPV |
| --- | --- | ---: | ---: | ---: |
| 0.54% (0/553, perfect-sensitivity 95% UB) | concealment only (channel) | 1.00 | 0.588 | **0.9%** |
| 0.54% (0/553, perfect-sensitivity 95% UB) | concealment gated on stage-2 | 0.188 | 0.0054 | **15.9%** |
| 1% | concealment only (channel) | 1.00 | 0.588 | **1.7%** |
| 1% | concealment gated on stage-2 | 0.188 | 0.0054 | **25.9%** |
| 0.1% | concealment gated on stage-2 | 0.188 | 0.0054 | **3.3%** |
| 1% | same, on a 90.5%-data-injection mix | 0.018 | 0.0054 | **3.2%** |

The 0.54% rows describe a detector that never misses; the sensitivity-adjusted
bound at the measured recall is 2.9%. Every row is a scenario or a bound, not a
forecast.

The channel alone has no operating point at document level; the gated version has
one only if sensitivity is reported honestly beside it.

## Reading it against F1

F1 measured extracted text: 11.7% of 290 crawl records carried an invisible code
point, and the concealment channel was empty. F4 measures the surface F1 could
not see — rendered markup — and the rate is far higher (58.8% vs 11.7%), though
the populations (job postings vs a crawl), the units (pages vs WET records) and
the channels (CSS state vs invisible Unicode) differ, so the two are not
like-for-like. The instruction count stays at zero in both, and the frames agree
on the conclusion and disagree on the mechanism: **concealment is a property
of the rendering stack, not a signal of an attack**; a detector keyed on it either
stays silent or reports that a page has UI state.

For an ingestion pipeline the sharper number is the text gap: an extractor that
reads DOM text instead of rendered text pulls a median **3,290 extra characters
per page** (p90 3,872, n=101) that no human reader sees.

## What this does not measure

- **Not pre-registered.** F1's standard was a frozen protocol; this frame was
  designed and run in one pass. Treat the intervals as descriptive.
- **Postings, not CVs.** The documented 1% lives in résumés/ATS documents
  (Zhang et al., USENIX Security 2026: 196,682 résumés, ~1%, 90.5% of it data
  injection). Nothing here transfers to the candidate side.
- **JavaScript enabled**, unlike `scripts/f4/render-hidden.js`: these ATS pages
  are client-rendered, and the question is what an agent's browser sees. A
  JS-disabled run would measure a different, smaller frame.
- **Comments on a subsample only**: 80 comment nodes across 101 pages re-parsed,
  none instruction-shaped; not measured on all 553.
- **Mechanism list is the ceiling**: four common CSS techniques score 0/72.
- Pages behind auth, canvas-drawn content, and vision-only concealment are out.

## Reproduce

```sh
python -m venv venv && ./venv/Scripts/python.exe -m pip install playwright   # Chromium reused, no download
python fetch_boards.py 40            # sample + provenance (one pass, 14 boards)
python render_runner2.py --shard 0 --of 4   # rendered concealment, 4 shards
python markup_scan.py  --shard 0 --of 4     # attributes / JSON-LD / meta / template
python analyze_render2.py && python ppv.py  # aggregates + inference
python inject_test.py payloads.json inject_results.set1.json   # held-out recall
```

Scripts live in `scripts/f4/python/`. No model is called; no page text is
published; `data/`, the raw captures and the per-page scan records stay local.
